## Overview

FORM helps you follow a timed movement plan, track session completion, and build consistency over time. It includes a coin-based movement shop, individual timer upgrades, and progress summaries — all in a responsive interface.

## Live Demo

**Website:** https://form-workout-tracker-anshu-codes.vercel.app

The live version is hosted on Vercel. You can use the website directly without installing anything.

## Features

- **Timed workout sessions** — Start, pause, reset, and skip movements.
- **Guided movement** — Spoken exercise announcements and an audio completion cue where supported by the browser.
- **Customizable durations** — Upgrade individual movement timers.
- **Coin reward system** — Complete the full session to claim coins and unlock additional movements.
- **Progress tracking** — View completed sessions, training days, active minutes, and consistency rank.
- **Session notes** — Save personal notes about each session.
- **Responsive design** — Use FORM on desktop or mobile browsers.

## Getting Started

FORM is a static website built with HTML, CSS, and vanilla JavaScript. No package installation or build step is required.

### Run locally

1. Clone this repository:

   ```bash
   git clone https://github.com/AnshuCodes0/form-workout-tracker.git
   ```

2. Open the project folder.
3. Open `index.html` in a modern web browser.

You can also download the repository as a ZIP and open `index.html` directly.

## Data & Privacy

- Workout progress and session notes are saved in the browser's local storage.
- Data is stored locally in the browser and is not automatically synchronized across devices or browsers.
- Clearing the browser's site data may remove locally saved progress.

## Important Note

FORM is a general-purpose movement tracker, not a medical or fitness assessment tool. Choose movements and durations that feel comfortable, take breaks when needed, and stop if you feel pain, dizziness, or unwell.
